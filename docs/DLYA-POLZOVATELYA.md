# Etemenanki — для пользователя

## Одна установка

1. **Скачайте** с [GitHub Releases](https://github.com/Baddysays/Etemenanki/releases/latest):
   - `EtemenankiSetup-1.0.5.exe` — полный установщик (~2 ГБ): приложение, Python и **TranslateGemma 4B** уже внутри
   - или portable ZIP — распаковать и запустить `Etemenanki.exe`

2. Установите → откройте → нажмите **Начать**.

3. **Перевод**: «Загрузить файл» → языки → «Перевести» → «Сохранить».

Ollama **не обязательна**. Встроенная модель — **TranslateGemma 4B** (специально для перевода).

## Обновления

**Настройки → Общие → Обновления → Проверить обновления**  
(или файл `releases/update.json` на GitHub).

## Две видеокарты

Если перевод долгий:

1. В **Настройки** выберите **дискретную** видеокарту (GeForce / RTX), не Intel UHD.
2. **Параметры Windows → Система → Дисплей → Графика** — для приложения укажите «Высокая производительность».

## Режимы ИИ

| Режим | Для кого |
|-------|----------|
| **Встроенная модель** | По умолчанию после установки — без Ollama |
| **Автоматически** | Может использовать Ollama, если она есть |
| **Свой Ollama** | Вы сами держите `ollama serve` и модели |

## Если что-то не работает

| Симптом | Что сделать |
|---------|-------------|
| Нет модели / не переводит | Настройки → «Докачать модель» или переустановите полный setup |
| PDF без текста | В установке должен быть Python; иначе Настройки / переустановка |
| PDF с вёрсткой | Опционально pdf2zh в установщике или Настройках |
| Облачный перевод | Настройки → Облако API — ключ и URL |
