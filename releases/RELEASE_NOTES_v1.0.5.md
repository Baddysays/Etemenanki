# Etemenanki 1.0.5

## Что нового

- Встроенная модель: **TranslateGemma 4B** (Q2_K, ~1.6 ГБ) — специально для перевода; квант выбран так, чтобы полный установщик укладывался в лимит GitHub Releases (2 ГиБ).
- Установщик self-contained: приложение + Python + модель (укладывается в лимит GitHub Releases 2 ГиБ).
- Исправления 1.0.4: путь Python, установщик без ложной «сборки не найдена», докачка модели из Настроек.

## Установка

1. Скачайте `EtemenankiSetup-1.0.5.exe`.
2. Установите → откройте → **Начать**.
3. Загрузите документ → **Перевести**.

Ollama не нужна для базового сценария.
