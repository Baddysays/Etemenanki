# Etemenanki 1.0.4

## Установщик «всё в одном»

- **EtemenankiSetup-1.0.4.exe** (~1.8 ГБ): приложение, Qt, встроенный Python, встроенная модель ИИ (~1.7 ГБ).
- После установки **не нужно** докачивать модель через интернет (только опционально pdf2zh ~200 МБ).
- Мастер первого запуска: экран «Всё готово» → **Начать**.

## Сборка релиза

```powershell
.\scripts\build_installer.ps1
```

См. `docs/INSTALLER.md`.
