# 06 — AGPL и лицензирование

## Затронутые компоненты

| Компонент | Лицензия | Как используется |
|-----------|----------|------------------|
| PDFMathTranslate (pdf2zh) | **AGPL-3.0** | Subprocess: `pdf2zh_runner.py` → pip package |
| PyMuPDF | **AGPL-3.0** | `pdf_layout.py`, extract, pdf2zh internally |

## Модель интеграции (black-box)

- Исходники pdf2zh **не** линкуются в C++/Qt.
- Вызов отдельным процессом Python с собственным интерпретатором (venv).
- Пользователь может заменить/обновить pdf2zh в venv или portable bundle.

## Обязанности при дистрибуции (кратко, не юр. консультация)

1. Предоставить исходники AGPL-компонентов или ссылку на получение (AGPL §6).
2. Сохранить уведомления об авторских правах.
3. UI: атрибуция в настройках / «О программе» (см. `SettingsDialog.qml`, `engines/THIRD_PARTY.md`).

## Portable bundle

- `tools/setup_pdf2zh.ps1` — официальный zip с GitHub releases.
- Не смешивать с проприетарным кодом в одном «модифицированном» бинарнике без соблюдения AGPL для производных работ.
