# Embedded Python (optional)

For a fully portable install, copy a Python 3.11+ embeddable or venv here:

```
engines/python/
  python.exe
  Lib/
  Scripts/   (pip packages: pymupdf, pymupdf-fonts, python-docx, openpyxl, …)
```

Etemenanki searches `engines/python/python.exe` before system Python.

Development builds use `.venv` via `tools/python_path.txt` (generated by CMake).
